# oiyo-news-discussions

[news.oiyo.net](https://news.oiyo.net)의 날짜별 토론 댓글을 보관하는 저장소예요.

- 댓글은 [giscus](https://giscus.app)를 통해 이 저장소의 GitHub Discussions에 저장돼요.
- 날짜 페이지 하나에 토론 하나가 이어져요. 새 토론은 giscus와 관리자만 만들 수 있어요.
- 댓글을 남기려면 GitHub 계정으로 로그인해야 하고, 남긴 댓글은 공개돼요.
- 삭제나 신고가 필요하면 해당 토론에서 신고하거나 support@oiyo.net으로 알려 주세요.
